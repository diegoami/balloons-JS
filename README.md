# Balloons

Pop the balloons before they get away. Twenty levels, twenty seconds each,
five lives. It can be won.

**[Play it in a browser](https://baloncelli.netlify.app)** · **[Download the Android app](../../releases/latest)**

---

## What it is

A canvas game, first written in December 2012 as an experiment: balloons, four
difficulty settings and a photograph of a sky. Rebuilt in 2026 — the sky is
drawn rather than photographed and runs from morning to night as you climb, and
the four difficulties became one ladder of twenty levels, so that every score on
the board was earned the same way.

| | |
| --- | --- |
| **Pop** | balloons, and the saucers that come to shoot you |
| **Leave alone** | birds and fireflies — both cost a life |
| **A run** | 20 levels × 20 seconds. 5 lives, plus one at levels 12, 15 and 18 |
| **New things arrive** | every other level, from 4 to 18 |

Best played on a tablet. The difficulty is calibrated against about 2.3 taps a
second from **one** pointer, and a touchscreen lets you use two thumbs — which
is, measured, the difference between dying around level 8 and finishing every
run.

## Installing the Android app

The app is about 2.7 MB and **plays with the radio off**. The whole game is on
the device; it only reaches the network to fetch and post high scores, and it
works perfectly well without that.

1. Download `app-release.apk` from [the latest release](../../releases/latest).
2. Open it. Android will say it cannot install apps from this source — that is
   the normal warning for anything not from the Play Store.
3. Tap **Settings** on that prompt, allow installs from whichever app you
   downloaded with (usually your browser), and go back.
4. Install.

It needs **Android 8.0 or newer** and one permission, `INTERNET`, used only for
the leaderboard.

### If you have an older copy installed

Android refuses to install an update signed with a different key than the one
already on the device. If the install fails with a signature error, uninstall
the old copy first — your high scores live on the server, not in the app, so
nothing is lost but the name you typed.

## Why it is not on the Play Store

No particular reason beyond effort. Sideloading is the honest option for a game
nobody is being charged for.
