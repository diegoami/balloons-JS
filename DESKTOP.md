# Baloncelli for Windows

The owner requested a new Windows download for itch.io after v2.8 had already
been published. The repository and its eight historical releases had no
desktop binary. [Issue #95](https://github.com/diegoami/balloons-JS/issues/95)
records the new platform design.

The wrapper follows Scopetta, Discola and Tressette: Tauri 2.11.6, CLI 2.11.5,
system WebView2, a portable unsigned Windows x64 executable and no installer.
It embeds `public/` directly, without a frontend build step. The window opens
at 1280×800 and can be resized down to 640×480. Its permanent storage identifier
is `com.diegoami.baloncelli.desktop`; changing it after distribution would
separate players from their existing name/history profile.

`desktop/src-tauri/src/main.rs` initializes the scores endpoint before the
game scripts run. Local name/history remain in the native app profile, while
the online board is shared. The app exposes no native shell API to JavaScript;
only the known HTTPS GitHub downloads-directory and release URLs may open externally.

## Build and check

See [desktop/README.md](desktop/README.md) for prerequisites. Dependencies are
installed in this checkout; node_modules/build outputs are never copied from
another project. Cargo.lock started from the other games' pinned stack and
was regenerated by Cargo for this package.

```powershell
cd desktop
npm ci
npm run build
cd ..
node tools/smoke_desktop.mjs
node tools/package_desktop.mjs --confirm
```

The smoke tests the actual executable via its temporary WebView2 debug
connection. It uses a fresh temporary profile, intercepts score requests and
never posts a smoke score to production. It checks packaged origin, 1280×800
viewport, initial scores URL, bundled font, actual name entry, start/popping
with a score increase, the HUD boundary, and name/history surviving a normal
restart. Clicking the prefilled name field cancels its initial selection, so
the driver explicitly selects all before entering a replacement. That was a
driver correction; no game input code was changed.

The external download opener is allowlisted in native code; the smoke does
not launch an external browser. Browser checks and page settings stay with
the owner. Physical manual testing is not claimed by the automated smoke.

## Publication provenance

The initial executable version is 2.8.0, matching the game version 2.8, but
**the native wrapper was not present in the reviewed v2.8 tag**. Do not attach
it as though that tag/review covered the new native code. The packager records
the actual source commit/tree and labels its output a Windows preview.

A stable desktop release needs a new reviewed source candidate. The owner
can explicitly authorize a clearly labelled preview/exception once the built
artifact is ready. The already-published browser/Android v2.8 tag remains
unchanged. Code signing and installers are deferred as in the other games;
downloaded unsigned executables can trigger the standard Windows publisher
warning.
